These are the questions that can be answered precisely today. The section will
grow as content is migrated from the previous site.

## Does this site show live flight status?

No. The airport supplies a weekly schedule as a single file, and that file
contains no actual or estimated times. The board therefore shows **scheduled
times** only, and never displays "delayed", "landed" or any similar status.

Showing those statuses would mean inventing them. For the current status of a
specific flight, contact your airline.

## Where does the board data come from?

Airport staff upload the weekly schedule file through the site's admin area.
Flights appear on the board as soon as that file is published.

The original schedule file stays available to download — the link is on the
flight board page.

## What if there are no flights today?

If the home page says there is no schedule for today, the new weekly file has
not been uploaded yet. The dates shown there tell you which week the published
data actually covers.

## Which languages is the site available in?

The site is fully available in Russian, English and Kazakh. The language
switcher is at the top of every page.

## Where is the airport?

Turkistan International Airport is at 43.30965, 68.54065. Links to Google Maps,
Yandex Maps and 2GIS are on the Contacts page.
